# Medical Rekordz CMS — Build Progress & Handoff

## What This Project Is

A custom PHP + MySQL CMS built from scratch for **Medical Rekordz** (a South African independent record label). Designed as a **sellable product** — any client can deploy it. Medical Rekordz is the first client deployment.

**Hosted on:** Xneelo Managed WordPress hosting (PHP + MySQL/MariaDB, cPanel)
**No WordPress dependency** — pure PHP, no Composer, deployable via cPanel file upload only.

---

## Two-Tier Auth Model

| Tier | Who | Login URL | Access |
|------|-----|-----------|--------|
| Admin | Website owner / client | `/admin/login` | Content, artists, media, settings, users |
| Super Admin | Developer (you) | `/{secret-slug}/login` | Everything + file manager, logs, DB backup, system info |

Super admin login URL is generated during install — never hardcoded, never shown twice.

---

## Architecture Decisions (Already Made — Do Not Revisit)

- **Option B** — Full PHP CMS rebuild (not patching the static site)
- **Singleton** Database pattern (no Composer DI)
- **Convention-based routing** — URI segments map to controllers automatically
- **Soft deletes** on content tables (`deleted_at` column)
- **Typed settings** — `setting_type ENUM('string','bool','int','json')`
- **No active record** — thin Model base, each model writes explicit query methods
- **Layout inheritance** in View — `$content` variable yielded inside layout files
- **Scope auto-detection** in Controller base — namespace determines layout automatically
- **Session-based brute force** for v1 — DB-backed upgrade path flagged for later
- `mrk_releases` and `mrk_tracks` in schema now, UI deferred to v2

## Namespace & File Conventions

```
Core\              → core/
App\Models\        → app/models/
App\Controllers\   → app/controllers/
App\Controllers\Admin\       → app/controllers/admin/
App\Controllers\Superadmin\  → app/controllers/superadmin/
```

**Routing convention:**
```
/                          → HomeController::index()
/artists/illrow            → ArtistController::show()  (with $id = 'illrow')
/admin                     → Admin\DashboardController::index()
/admin/artists/edit/5      → Admin\ArtistController::edit(5)
/{slug}                    → Superadmin\DashboardController::index()
/{slug}/logs               → Superadmin\LogViewerController::index()
```

**View layout system:**
- Layouts live at `app/views/layouts/{public|admin|superadmin}.php`
- Layout files echo `<?= $content ?>` at the yield slot
- `View::render('admin/dashboard/index', $data)` — scope auto-passed from Controller
- `View::partial('admin/sidebar')` — no layout, inline include
- `View::toString('email/contact')` — returns string, used by Mailer
