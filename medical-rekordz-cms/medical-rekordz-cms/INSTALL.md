# Medical Rekordz CMS — Installation Guide

## What You Need

- PHP 8.0 or higher
- MySQL 5.7+ or MariaDB 10.3+
- A web host with cPanel (like Xneelo) or any server that runs PHP + MySQL

---

## Step 1 — Upload Files

1. Download or zip the entire CMS folder
2. Upload it to your hosting via cPanel File Manager or FTP
3. Make sure `public/` is your web root (the folder your domain points to)

**If your host points to `public_html/`:**
- Upload everything into `public_html/`
- Move the contents of the `public/` folder into `public_html/`
- Update the paths in `public/index.php` if needed

**If your host lets you set the document root:**
- Point your domain's document root to the `public/` folder inside the CMS

---

## Step 2 — Create the Database

1. Log into cPanel
2. Go to **MySQL Databases**
3. Create a new database (e.g. `medical_rekordz`)
4. Create a new database user with a strong password
5. Add the user to the database with **ALL PRIVILEGES**
6. Write down the database name, username, and password — you'll need them next

---

## Step 3 — Run the Installer

1. Open your browser and go to: `https://yourdomain.com/install/`
2. The installer will check your server meets the requirements
3. Enter your database details (name, username, password, host — usually `localhost`)
4. Enter your site name and create your Super Admin account
5. The installer generates a **secret URL** for Super Admin access — **save this somewhere safe, it won't be shown again**
6. Click Install

The installer will:
- Create all 13 database tables
- Write your config files
- Seed default settings
- Create a lock file so the installer can't be run again

---

## Step 4 — Set Folder Permissions

These folders need to be writable by PHP:

```
storage/uploads/    — chmod 755
storage/logs/       — chmod 755
storage/backups/    — chmod 755
storage/cache/      — chmod 755
```

In cPanel File Manager: right-click the folder → Change Permissions → set to 755.

---

## Step 5 — Log In

- **Admin panel:** `https://yourdomain.com/admin/login`
- **Super Admin:** `https://yourdomain.com/{your-secret-slug}/login` (the URL from Step 3)

---

## Step 6 — Configure Your Site

Once logged in as Admin:

1. **Settings** — Set your site name, about text, social media URLs
2. **Artists** — Add your artists with profile images and bios
3. **Videos** — Add YouTube video URLs
4. **Pages** — Create any additional pages (About, Press, etc.)
5. **Navigation** — Set up your menu items
6. **Media** — Upload images and files

---

## Troubleshooting

**Blank white page:**
- Check `storage/logs/app.log` for errors
- Make sure PHP 8.0+ is selected in cPanel → MultiPHP Manager

**404 on all pages:**
- Make sure `.htaccess` files are uploaded (they're hidden files)
- Check that `mod_rewrite` is enabled on your server

**Can't upload files:**
- Check `storage/uploads/` has write permissions (755)
- Check your PHP `upload_max_filesize` in cPanel → MultiPHP INI Editor (set to at least 50M)

**Installer won't load:**
- Delete `install/install.lock` if you need to re-run the installer
- Make sure your database credentials are correct

**Forgot Super Admin URL:**
- Check `config/superadmin.php` — the slug is stored there

---

## Security Notes

- The `config/` folder is blocked from web access by `.htaccess`
- The `storage/` folder is blocked from direct web access
- The `install/` folder is locked after installation
- Super Admin URL is randomly generated and hidden
- All forms are protected with CSRF tokens
- File uploads are validated by MIME type and size (50MB max)
- Passwords are hashed with bcrypt

## File Structure

```
medical-rekordz-cms/
├── app/
│   ├── controllers/       ← Route handlers
│   ├── models/            ← Database queries
│   └── views/             ← PHP templates
├── config/                ← Settings (auto-generated by installer)
├── core/                  ← Framework classes
├── install/               ← Web installer
├── public/                ← Document root (point domain here)
│   ├── assets/css/        ← Stylesheets
│   ├── assets/js/         ← JavaScript
│   └── index.php          ← Entry point
├── storage/               ← Uploads, logs, backups
├── INSTALL.md             ← This file
└── PROGRESS.md            ← Build log
```
